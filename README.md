《凡人修仙传》主题 Minecraft 服务器的客户端文件(模组 + 配置 + 材质包)。
**不需要 GitHub 账号,下面都是直接下载。**

服务器地址:**`103.37.44.89:12788`**

---

## 版本要求

| 项 | 要求 |
|---|---|
| Minecraft | **1.20.1** |

## 安装步骤

### 1. 下载文件

**方式 A:下载整包(推荐,一次拿全)**

点本页右上角绿色 **Code → Download ZIP**,或直接点这个链接:

**https://github.com/qw1056511292-del/fanren-xiuxian-client/archive/refs/heads/main.zip**

解压后是 `mods / config / resourcepacks` 三个文件夹 + 一份 `使用说明.txt`,
按下面第 2 步复制即可。

**方式 B:从 Releases 逐个下载**

打开 **[下载页(Releases)](https://github.com/qw1056511292-del/fanren-xiuxian-client/releases/latest)**,
在页面下方的 **Assets** 里下载(不需要登录)。如果 Releases 页的文件版本看起来比仓库旧,
以方式 A 的整包为准。

**材质包(1 个)**

| 文件 | 放到哪 |
|---|---|
| `fanren-xiuxian-resourcepack.zip` | `resourcepacks` 文件夹 |

**模组(10 个,全部都要下)**

| `curios-forge-5.14.1+1.20.1.jar` | 饰品栏前置 |
| `epic-fight-20.14.8-mc1.20.1-forge.jar` | 魂类战斗本体(翻滚 / 耐力 / 硬直) |

> 缺这个前置进服会报"缺少前置 / 红叉",不是别的装错了。

### 2. 放文件

打开你的游戏目录(启动器里一般有"打开游戏目录"按钮),把三个文件夹复制进去:

```
你的游戏目录/
├── mods/                    ← 上面全部 .jar 模组(10 个 + 自己下的 Invincible Lib)
├── config/                  ← 3 个 .toml(方式 A 整包里自带)
└── resourcepacks/           ← 凡人修仙传-材质包.zip
```

- 目标文件夹不存在就自己建一个同名文件夹。
- 材质包文件名保持 `凡人修仙传-材质包.zip` 即可;
  方式 B 下载的 `fanren-xiuxian-resourcepack.zip` 建议改回这个名字。
- 不要把 `resourcepacks` 里的 zip 放进 `mods`,反过来也不行。

### 3. 在游戏里启用材质包(这步不能省)

**光把材质包放进文件夹是不会生效的。** 按这个顺序操作一次:

1. 启动游戏,进 **选项 → 资源包**
2. 在左侧"可用"列表里找到 **凡人修仙传-材质包**,点箭头把它移到右侧"已选"列表
3. 点"完成"

漏了这步的表现是:能进服,但灵草、丹药、3D 模型全是原版的样子 —— 而且**游戏不会报任何错**。

### 4. 进服

多人游戏 → 添加服务器 → 地址填 `103.37.44.89:12788`。

第一次进服的玩家需要按提示先 **`/register <密码> <密码>`** 注册(密码至少 8 位),
之后每次进服用 **`/login <密码>`** 登录。登录前不能移动和查看背包,这是正常的。

进服第一天:右键背包里的"引路玉简"(司南玉盘)跟着走;敲 `/guide` 看完整手册;
按 `K` 打开修仙录主面板。

### 5. 按键速查(完整版与改键方案见 `使用说明.txt` 第八步)

| 键 | 功能 |
|---|---|
| 右键(持剑/法器) | 施放绑定的神通 |
| 潜行 + 右键 | 打开武器神通绑定菜单 |
| `K` | 修仙录主面板 |
| `G` | 缩地术(追风履) |
| `左Alt` | 御剑瞬闪(地面是 Epic Fight 闪避) |
| `Z` / `X` | 法术轮盘 / 释放法术(法修) |
| `N` | Epic Fight 技能树(御剑凌虚) |

默认键位有重叠(`G`、`K`、`X` 等),**建议按 `使用说明.txt` 第八步改一次**,以后不再冲突。

### 6. 魂类战斗与御剑(2026-09 新增)

- 本服是 Epic Fight 魂类战斗:翻滚、耐力、受击硬直,前摇更明显、能被打断,这是刻意设计。
- 按键在 **设置 → 按键 → Epic Fight / Epic Fight: Skill Tree** 分类里看。
- 御剑凌虚的御剑飞行 / 万剑归宗等动作是 **Epic Fight 技能**,要先学会:
  1. 按 `N` 打开**技能树**,在「御剑凌虚」页用能力点解锁节点
     (能力点:打怪掉的能力石,或技能树界面里用经验兑换);
  2. 解锁即自动学会,再用 Epic Fight 的技能编辑界面装到技能槽;
  3. 战斗模式下按技能键释放;第一人称看不到自己的动作,按 `F5` 切第三人称。
- 服务器锁定「战斗模式」:看到 "Switching vanilla/epicfight mode is disabled..." 是设计如此,
  不是故障。
- 御剑工艺默认键:`V` 召出/收回飞剑、`H` 剑阵、`R` 切换阵型、`J` 切换御器术式、
  `K` 切换剑阵变式、`X` 连势、`G` 御器交互、`B` 器灵避让、`I` 打开配置、
  `Ctrl+G` 快捷切换、双击空格御剑飞行。
  **这些键与其它模组有重叠,见 `使用说明.txt` 第八步的改键方案。**

## 更新时怎么做

服务器内容更新时,整包与 Releases 下载页里的文件会重新上传:

1. **重新下载**整包(方式 A),覆盖 `mods` / `config` / `resourcepacks` 里的旧文件;
2. 进游戏 → **选项 → 资源包**,确认右侧"已选"列表里**仍有**"凡人修仙传-材质包"
   (覆盖文件之后偶尔会被游戏取消勾选,扫一眼就好);
3. 模组按上面的表补齐 / 覆盖;文件名带版本号,旧文件删掉
   (尤其 xiuxianforge 别留两个版本,同名模组重复会导致启动失败)。

## 常见问题

**Q:进游戏提示缺模组 / 连不上服?**
A:确认游戏是 **1.20.1 + Forge 47.4.18**,并且上表里的模组**一个不缺**(含自己下的 Invincible Lib)。
版本不对或漏装是最常见的原因。

**Q:物品图标、模型没变,还是原版的?**
A:材质包没有启用。见"安装步骤 3",在 选项 → 资源包 里确认它在右侧"已选"列表。

**Q:按 N 打不开技能树?**
A:没装 `epicfight-skilltree-forge-...jar`,或者按键被别的模组占了(设置 → 按键 里改)。

**Q:进服后被冻住 / 打不了字?**
A:登录。`/login <密码>`,第一次进服的先 `/register`。

**Q:打不开 GitHub 链接?**
A:多试几次,或者换个网络(国内访问 GitHub 偶尔不稳定)。
