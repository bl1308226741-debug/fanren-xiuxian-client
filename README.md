# 凡人修仙传 —— 客户端下载

《凡人修仙传》主题 Minecraft 服务器的客户端文件(材质包 + 模组)。
**不需要 GitHub 账号,下面都是直接点击下载。**

服务器地址:**`103.37.44.89:12788`**

## 版本要求

| 项 | 要求 |
|---|---|
| Minecraft | **1.20.1** |
| 模组加载器 | **Forge 47.4.x**(推荐 [47.4.23](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)) |

游戏本体的安装方法网上都有(先装 Forge,再用启动器建一个 1.20.1-forge 的版本)。

## 安装步骤

### 1. 下载三个文件

- **材质包**:[凡人修仙传-材质包.zip](https://github.com/qw1056511292-del/fanren-xiuxian-client/releases/latest/download/fanren-xiuxian-resourcepack.zip)(下载后把文件改名为 `凡人修仙传-材质包.zip`,不改也能用)
- **模组**:[xiuxianforge-0.1.0.jar](https://github.com/qw1056511292-del/fanren-xiuxian-client/raw/main/mods/xiuxianforge-0.1.0.jar)
- **模组**:[curios-forge-5.14.1+1.20.1.jar](https://github.com/qw1056511292-del/fanren-xiuxian-client/raw/main/mods/curios-forge-5.14.1%2B1.20.1.jar)

### 2. 放文件

打开你的游戏目录(启动器里一般有"打开游戏目录"按钮),里面有两个文件夹:

```
你的游戏目录/
├── mods/                    ← 两个 .jar 模组放进这里
│     ├── xiuxianforge-0.1.0.jar
│     └── curios-forge-5.14.1+1.20.1.jar
└── resourcepacks/           ← 材质包 zip 放进这里
      └── 凡人修仙传-材质包.zip
```

- 两个 `.jar` 文件放进 **`mods`** 文件夹(没有这个文件夹就自己建一个)。
- 材质包 `.zip` 放进 **`resourcepacks`** 文件夹。

### 3. 在游戏里启用材质包(这步不能省)

**光把材质包放进文件夹是不会生效的。** 按这个顺序操作一次:

1. 启动游戏,进 **选项 → 资源包**
2. 在左侧"可用"列表里找到 **凡人修仙传-材质包**,点箭头把它移到右侧"已选"列表
3. 点"完成"

漏了这步的表现是:能进服,但灵草、丹药全是原版图标 —— 而且**游戏不会报任何错**。

### 4. 进服

多人游戏 → 添加服务器 → 地址填 `103.37.44.89:12788`。

第一次进服的玩家需要按提示先 **`/register <密码> <密码>`** 注册(密码至少 8 位),
之后每次进服用 **`/login <密码>`** 登录。登录前不能移动和查看背包,这是正常的。

## 更新时怎么做

服务器内容更新时,这个页面里的文件会重新上传:

1. **重新下载**材质包 → 覆盖 `resourcepacks` 里的旧文件
2. 进游戏 → **选项 → 资源包**,确认右边"已选"列表里**仍有**"凡人修仙传-材质包"
   (覆盖文件之后偶尔会被游戏取消勾选,扫一眼就好)
3. 模组如果提示更新,下载新的 `.jar` 覆盖 `mods` 里的旧文件(文件名带版本号,
   旧文件可以删掉)

## 常见问题

**Q:进游戏提示缺模组 / 连不上服?**
A:确认游戏是 **1.20.1 + Forge**,两个模组都在 `mods/` 里。版本不对是最常见的原因。

**Q:物品图标没变,还是原版的?**
A:材质包没有启用。见"安装步骤 3",在 选项 → 资源包 里确认它在右侧"已选"列表。

**Q:进服后被冻住 / 打不了字?**
A:登录。`/login <密码>`,第一次进服的先 `/register`。

**Q:打不开 GitHub 链接?**
A:多试几次,或者换个网络(国内访问 GitHub 偶尔不稳定)。
